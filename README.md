# Word Embeddings and Bigram Language Model

## Project Overview

This project demonstrates fundamental Natural Language Processing (NLP) techniques using Python and NumPy.

It implements Skip-Gram based Word Embeddings and a Bigram Language Model to explore word representations, contextual relationships, probability estimation, and next-word prediction.

## Implemented Techniques

### 1. Skip-Gram Word Embeddings

- Text tokenization.
- Vocabulary generation.
- Word-to-index mapping.
- Context-window generation.
- Word embedding initialization.
- Softmax probability calculation.
- Gradient-based weight updates.
- Training over multiple epochs.
- Generation of 10-dimensional word embeddings.

### 2. Bigram Language Model

- Text preprocessing and tokenization.
- Unigram and bigram frequency calculation.
- Conditional probability estimation.
- Bigram probability dictionary construction.
- Next-word prediction.
- Prediction probability calculation.
